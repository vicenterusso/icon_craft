## 0.2.0

* Added automatic text scaling support via `IconThemeData(applyTextScaling: true)`
  * IconCraft now automatically respects `textScaleFactor` from `MediaQuery` when enabled
  * Both primary and secondary icons scale proportionally
  * Maintains backward compatibility - existing code without `applyTextScaling` continues to work unchanged
